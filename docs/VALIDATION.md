# 実装時の検証

2026-10-26 にローカル環境の Chromium 154 / Lighthouse 13.5 で確認しました。実写真、Google Forms、GA4、SNS の本番接続および公開先の配信性能は未検証です。これらの設定後に再検証してください。

## 実行した確認

- 全9ページ × 8画面幅（320 / 375 / 390 / 430 / 768 / 1024 / 1440 / 1920px）。横はみ出しとJavaScript例外なし。
- 初回イントロと同一セッションでの省略。モーション軽減設定時は演出を省略。
- モバイルメニュー開閉、Escape、フォーカス復帰。
- ギャラリー12枠、実画像を使ったライトボックスの前後移動・Escape・フォーカス復帰。
- CMSデータをテスト用に差し替え、ニュースの最新3件・日付順・カテゴリー絞り込み、レース結果の0ポイント、次戦情報を確認。
- CMSのHTML文字列をテキストとして表示し、危険なURLと不正なGoogle Formsの接続先を拒否。
- 実画像・メール・電話・正しいGoogle Forms埋め込みURLの反映。フォームはテスト応答を使用し、外部へ問い合わせは送信していません。
- JavaScript無効時の本文・ページ一覧。初期表示に外部フォント、SNS埋め込み、ギャラリー実画像の一括通信なし。
- Pages CMS公式の設定スキーマに対する `.pages.yml` の検証。
- 公開URL変更時のcanonical・OGP・sitemap・JSON-LD・CSPハッシュの生成。

## 再実行

依存パッケージ不要の検証：

```bash
python3 scripts/build.py
python3 scripts/check_site.py dist
```

ブラウザーでは、PC・スマートフォンでメニュー、各リンク、ニュース、写真、フォーム、キーボード操作を確認してください。Chrome DevTools の Lighthouse で上記4項目を測定し、Network で画像容量・遅延読み込み・外部通信を確認してください。公開後は PageSpeed Insights / Search Console の実データも確認します。
