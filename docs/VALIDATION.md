## 再実行

依存パッケージ不要の検証：

```bash
python3 scripts/build.py
python3 scripts/check_site.py dist
```

ブラウザーでは、PC・スマートフォンでメニュー、各リンク、ニュース、写真、フォーム、キーボード操作を確認してください。Chrome DevTools の Lighthouse で上記4項目を測定し、Network で画像容量・遅延読み込み・外部通信を確認してください。公開後は PageSpeed Insights / Search Console の実データも確認します。
