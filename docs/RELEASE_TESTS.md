## ローカルの速度・不要通信の観測

上記のローカル代替応答による測定は、DOMContentLoaded約288.0ms、load約291.4ms、LCP約320.0ms、CLS 0でした。最初の表示ではギャラリーと共通の写真パス12件中1件を取得しています。トップ画像09と共通のリソースも含む数え方で、ギャラリー要素を一括取得したという意味ではありません。各ギャラリー画像には遅延読み込みを設定しています。最大の最適化済み画像は465,454バイトでした。

**この値は本番Lighthouse、実利用者のCore Web Vitals、CDN性能、同時接続保証ではありません。** 開始時の原写真19ファイルは計6,387,789バイト、追加後20ファイルは計6,788,332バイトです。全配信派生画像の最終物理合計は5,343,106バイトです。後者は複数サイズを含む全体で、1ページ初回の転送量ではありません。最適化しても小さな原JPEGより大きくなる派生版もあり、全画像が必ず原本以下の容量とはしていません。
